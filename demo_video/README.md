# Demo videos

The four demo videos are too large for Canvas and GitHub, so they are hosted on Google Drive:

**[Open the demo videos folder](https://drive.google.com/drive/folders/1ea-xmgQnub5iQU8CR37_TBDoRQyfn07H?usp=sharing)**

| Video | What it shows |
|---|---|
| Task 1 – PDF support | Loading a PDF page by page, indexing a different PDF, and answering with the source page |
| Task 2 – Handbook chatbot | The RAG pipeline, correct answers, failure cases with their retrieved chunks, out-of-scope refusals, and the evaluation results |
| Task 3 – Docker deployment | The Dockerfile and Compose services, starting the stack, the app running in containers, and the index persisting across a restart |
| Task 4 – Web interface | Streamed answers, the Sources panel, follow-up questions, switching models and settings, and exporting the chat |
